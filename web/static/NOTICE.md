This distribution adds a TypeScript port, input validation, explicit summary
policies, local file handling, a worker, and a browser interface in 2026.
The original R files are retained as numerical reference sources. No claim of
Province of British Columbia endorsement is made. The code retains the legacy
model's recurrence; see the method document for deliberate wrapper changes.

Published forDRAT results use a later, separate workflow and are not produced
by this port. Climate scenario inputs here are supplied by the user.
